HTML Improvements
1. Semantic Structure (Headings)
You are using <h1> tags inside your <h2> classes. HTML headings should follow a logical, hierarchical order (h1 then h2 then h3, etc.).
Change: Replace the <h1> tags within your <section> elements with <h2>. Your main page title (if one existed in your header) would be the h1.

2. Accessibility & Best Practices
HTML Validation:
The width and height attributes on your <img> tags (.DQ-logo, the a link image) are not standard HTML5 attributes for responsiveness when using CSS for sizing. It's better practice to manage dimensions solely in CSS, but keeping them helps with page loading efficiency.
The width="296" on the "Contact Us" image should ideally be removed if CSS controls the width, or added as width and height attributes (though they will be overwritten by CSS).
Link Alt Text: The anchor tag wrapping the "Go UP" button has alt="Go back to the home page." in the image. This alt text is slightly confusing: the image is titled "GO UP" and links to #top, suggesting it goes to the top of the current page, not the home page.
Improvement: Change the alt text to something more accurate:

Use code with caution.

Image Sizing: The width attributes on the logo images are helpful, but the aspect ratios in your HTML attributes (width="720" height="278.5") use a decimal height, which isn't valid for HTML attributes. The browser will likely ignore the decimal part, but it's cleaner to use integers.
3. Redundant Dividers
You have a lot of div elements solely used for styling (specifically the .divider class). This works fine, but in modern CSS layouts, we try to achieve spacing using margin or gap on container elements (<footer>, <section>) rather than relying on empty structural divs.
Consideration: You could remove most of the .divider divs and add margin/padding to the adjacent <section> or <footer> elements instead.
